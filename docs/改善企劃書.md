# 森羅物語：草本 — 重製版 v1.1 改善企劃書

- 基準：`Kaleidoscope_Herbal_v1.2.13.mcaddon`（舊線最終版）
- 本線：重製版，版本自 **1.1.0** 起算，只給新世界使用
- 狀態：第三版，隨實作更新

## 1. 摘要

重製版的方向已定為四條原則：

1. **只有熟與焦**：湯劑取消下／中／上三品。
2. **每味藥材都有用途**：11 種藥材各自至少有一個藥方或料理，效果比照藥水。
3. **沒有無作用的東西**：沒有功能的物品、程式、文字一律移除。
4. **器具用 Cookery 的**：晾曬、切片、研磨交給 Cookery，草本不另做重複的工作台。
5. **散劑自己配**：藥材先磨粉，再用藥缽調配；配錯得到效果隨機的奇怪藥散；藥方用藥籤學。

1.1.0 已依這五條完成改動，並開放對外 API、檢查 PBR、建立測試與工具。
尚未做的是全部的實機測試。

## 2. 版本重製的影響

| 項目 | 1.1.0 的做法 |
|---|---|
| 版本號 | 兩個 manifest、圖鑑、Tavern 註冊資料一律 1.1.0；腳本從 `scripts/data/version.js` 一處讀取 |
| UUID | 沿用 1.2.13 |
| 舊世界 | 不支援。下品／上品湯劑、三個工作站、炮製品、藥刀已刪除，舊世界裡的這些東西會消失；舊資料遷移程式也已移除 |

版本號比 1.2.13 低而 UUID 相同，遊戲會把 1.1.0 視為較舊的版本。若同一台裝置上還留著 1.2.13，
建新世界時要確認選到的是 1.1.0。若希望徹底避免混淆，可改用新的 UUID，由你決定。

| 實體 | 藥碾與藥缽的動畫實體、舊版百子櫃儲存實體 | 隨工作站移除；儲存實體只為舊世界遷移而留 |

草本自己的器具：砂鍋（煎藥，有火候與燒焦機制）、藥缽（調配散劑）、香爐、百子櫃、藥鋤、藥方籤、藥方手札。

結果：方塊 60 → 55；物品 94 → 107（移除 11 種，新增 9 種藥粉、9 種散劑、藥方手札、封緘藥籤與 4 種湯劑）；腳本 52 → 48 檔。

**Cookery 現在是必要的。** 晾曬、切片、研磨、藥膳、茶都在 Cookery 的器具上完成；沒裝 Cookery 只能採集、種植，以及用藥廬箱子裡的乾藥材煎藥。

## 5. 散劑：磨粉、調配、學方

### 5.1 流程

| 步驟 | 做法 |
|---|---|
| 磨粉 | 乾藥材在 Cookery 石磨磨成粉 ×2。11 種藥材各有一種粉（靈芝粉、艾絨沿用，其餘 9 種新增） |
| 調配 | 藥缽放入二至三味藥粉，空手搗三下，得散劑 ×2。蹲下空手可取回最後放入的藥粉 |
| 配對 | 藥粉組合（不分順序）對上散劑方 → 得到該散劑 |
| 配錯 | 得到「奇怪藥散」，效果從 14 種好壞參半的效果裡決定 |
| 服用 | 直接吃，給藥水類效果與寒熱值 |
| 得方 | 圖鑑不寫散劑的配方，只能自己試，或取得藥方籤 |
| 封緘藥籤 | 山野藥廬的箱子有 35% 機率出一張；使用後拆封，變成寫好的藥方籤，內容是隨機一個散劑方 |
| 抄方 | 剛配成散劑時，蹲下手持空白藥方籤右鍵藥缽抄下配方（湯劑照舊對砂鍋抄） |
| 學方 | 對空使用寫好的藥方籤 → 記進自己的藥方手札；藥籤不消耗，可以傳給別人 |
| 翻閱 | 使用藥方手札（書 + 藥方籤合成）查看學過的藥方與配法 |

奇怪藥散的規則：同一組錯配在同一個世界永遠是同一種效果，藥包上有印記（✦ 加數字），印記相同就是同一種，可以堆疊；
換一個世界，對應關係重新洗牌。所以玩家可以自己試、自己記，但抄不到別的世界的答案。

藥缽現在只負責調配，不再研磨；研磨是 Cookery 石磨的事。

### 5.3 為什麼用藥方手札而不是圖鑑

圖鑑是草本把整份內容送給 Cookery 顯示，草本這一端的介面沒有「依玩家顯示」的欄位，所有人看到的都一樣。
所以依你的指示做了藥方手札：學過的藥方存在玩家身上，用手札翻閱。
圖鑑的散劑頁只寫效果，不寫配方；湯劑的配方照舊列出。

封緘藥籤目前只放在草本自己的山野藥廬箱子。原版寶箱（地牢、村莊等）沒有動：
要改它們必須覆寫原版戰利品表，會和其他覆寫同一張表的模組互相蓋掉。若仍要放，請指定哪幾種寶箱。

若 Cookery 之後提供依玩家顯示的圖鑑介面，手札的資料可以直接接過去。
