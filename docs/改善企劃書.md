# 森羅物語：草本 — 重製版 v1.1 改善企劃書

- 基準：`Kaleidoscope_Herbal_v1.2.13.mcaddon`（舊線最終版）
- 本線：重製版，版本自 **1.1.0** 起算，只給新世界使用
- 狀態：第二版，隨實作更新

## 1. 摘要

重製版的方向已定為四條原則：

1. **只有熟與焦**：湯劑取消下／中／上三品。
2. **每味藥材都有用途**：11 種藥材各自至少有一個藥方或料理，效果比照藥水。
3. **沒有無作用的東西**：沒有功能的物品、程式、文字一律移除。
4. **器具用 Cookery 的**：晾曬、切片、研磨交給 Cookery，草本不另做工作台。

1.1.0 已依這四條完成改動，並開放對外 API、檢查 PBR、建立測試與工具。
尚未實作的是「混合藥粉」與「藥籤學習」（第 5 節），以及全部的實機測試。

## 2. 版本重製的影響

| 項目 | 1.1.0 的做法 |
|---|---|
| 版本號 | 兩個 manifest、圖鑑、Tavern 註冊資料一律 1.1.0；腳本從 `scripts/data/version.js` 一處讀取 |
| UUID | 沿用 1.2.13 |
| 舊世界 | 不支援。下品／上品湯劑、四個工作站、炮製品已刪除，舊世界裡的這些東西會消失；舊資料遷移程式也已移除 |

版本號比 1.2.13 低而 UUID 相同，遊戲會把 1.1.0 視為較舊的版本。若同一台裝置上還留著 1.2.13，
建新世界時要確認選到的是 1.1.0。若希望徹底避免混淆，可改用新的 UUID，由你決定。

## 3. 1.1.0 的內容變更

### 3.1 湯劑：熟與焦

| 項目 | 之前 | 現在 |
|---|---|---|
| 成品 | 每方下品、中品、上品三種 | 每方一種（原中品的藥效）；煮過頭是焦糊藥渣，配錯是苦澀藥渣 |
| 文火／武火 | 影響品級 | 武火快一倍，但保溫只有 20 秒（文火 60 秒），更容易焦 |
| 佐使 | 紅棗、茯苓、冬蟲夏草提品；枸杞、冬蟲夏草加份量 | 只剩加份量：枸杞、冬蟲夏草各多一份，每鍋上限四份 |

| 殘根 | 降兩級 | 入鍋等同人參，但不能切片，產量只有三分之一 |

### 3.3 移除的東西

| 類別 | 移除 | 原因 |
|---|---|---|
| 物品與方塊 | 下品／上品湯劑 6 種 | 取消三品 |
| 物品 | 蜜炙甘草、酒炙當歸 | 原本只用來提品，取消三品後沒有作用 |
| 工作站 | 簸箕、鍘刀、藥碾、藥缽 | 與 Cookery 的竹篩、砧板、石磨重複 |
| 實體 | 藥碾與藥缽的動畫實體、舊版百子櫃儲存實體 | 隨工作站移除；儲存實體只為舊世界遷移而留 |
| 程式 | 4 個工作站元件、動畫、顯示遷移、百子櫃遷移、空函式與未使用的匯出 | 無作用 |
| 相依 | `@minecraft/server-ui` | 腳本沒有使用 |
| 文字 | 行為包語言檔縮為只有名稱與說明；資源包移除 71 個沒有被引用的鍵 | 無作用 |
| 結構 | 山野藥廬裡的簸箕改為空氣 | 方塊已移除 |

保留的器具：砂鍋（煎藥，有火候與燒焦機制）、香爐、百子櫃、藥鋤、藥刀（帶 Cookery 菜刀標籤，在 Cookery 砧板上使用）。

結果：檔案從 940 個降到 846 個；方塊 60 → 54，物品 94 → 88，腳本 52 → 45 檔。

**Cookery 現在是必要的。** 晾曬、切片、研磨、藥膳、茶都在 Cookery 的器具上完成；沒裝 Cookery 只能採集、種植與使用乾藥廬箱子裡的藥材煎藥。

## 5. 下一步：混合藥粉與藥籤學習（未實作）

需求：藥粉可以自己調配，效果類似藥水；配錯得到效果隨機的「奇怪藥方」；藥方可以從藥籤學進圖鑑。

### 5.1 提案

| 環節 | 做法 |
|---|---|
| 單味藥粉 | 乾藥材在 Cookery 石磨研成粉。現有靈芝粉、艾絨，其餘藥材各加一種粉 |
| 調配 | 在砂鍋以外不新增工作站：手持空藥包，對 Cookery 石磨（或工作台）依序放入二至三味藥粉，合成一包「混合藥粉」 |
| 判定 | 藥粉組合對上已定義的散劑方 → 得到該散劑；對不上 → 「奇怪藥方」 |
| 服用 | 直接服用，給藥水類效果與寒熱值。奇怪藥方從一張好壞參半的表隨機抽一個效果 |
| 同一世界的隨機 | 同一組錯誤配方在同一世界永遠得到同一個效果，玩家可以記錄、交流；不同世界不同 |
| 藥籤 | 沿用現有藥方籤：對著成品抄方（散劑與湯劑皆可），可交易、放進箱子 |
| 學習 | 手持寫好的藥籤使用 → 該玩家學會此方，藥籤消耗；已學會的方子在圖鑑顯示完整配方，未學會的只顯示名稱與剪影 |

### 5.2 需要先確認的事

1. **調配地點**：石磨一次只吃一種材料。混合要用工作台的無序合成（最簡單，但錯誤組合要逐一產生配方檔），還是請 Cookery 開一個多材料的器具介面？
2. **圖鑑的個人進度**：圖鑑目前由草本整份送給 Cookery 顯示，所有玩家看到的內容相同。「學會才顯示」需要 Cookery 圖鑑支援依玩家隱藏條目；若不支援，替代做法是用玩家身上的一本「藥方手札」物品記錄已學的方子。
3. **散劑清單**：要幾個方、各用哪些藥粉、給什麼效果。
4. **美術**：每種藥粉與散劑都需要圖示與 PBR 貼圖。
