## 7. 砂鍋

放法：砂鍋正下方要有熱源。

### 7.1 基本流程

- [ ] 👤 水桶右鍵加水（水桶變空桶）→ 放入藥材（最多六份）→ **蹲下空手右鍵**開火 → 煮好後手持碗右鍵盛湯。
- [ ] 👤 煎煮中：鍋蓋關閉、白汽、沸騰聲。煮好：鍋蓋微掀、淡金汽、一聲完成音。
- [ ] 👤 鍋口看得到最後放進去的那味藥材。
- [ ] 👤 空鍋或沒有熱源時開火：只冒煙嘶響，不會開始。
- [ ] 👤 放滿六份再放：輕輕「喀」一聲，放不進去。
- [ ] 👤 煮到一半移開熱源：暫停；放回熱源繼續。

### 7.2 熱源

- [ ] 👤 文火：已點燃的營火、靈魂營火、廚房爐灶。
- [ ] 👤 武火：火、靈魂火、岩漿、熔岩塊、燃燒中的熔爐類。速度兩倍。
- [ ] 👤 ⚠️ **點燃的蠟燭、亮著的銅燈放在砂鍋下不能煎藥**（這次改的：以前任何有「點燃」狀態的方塊都算熱源）。
- [ ] 👤 熄滅的營火不能煎藥。

## 14. 對外 API ⚠️

這一節要另一個模組來呼叫才測得到。目前倉庫裡**沒有**測試用模組；需要的話 Claude 可以做一個小的範例模組（註冊一個藥方、一個佐使、一種食物的寒熱，並把收到的事件印在內容記錄）。

有了範例模組之後要測的：

- [ ] 👤 握手：內容記錄印出草本的版本 1.1.0 和 capabilities。
- [ ] 👤 外部藥方：把範例模組的材料放進砂鍋，煎得出它的成品；份數正確；也會焦。
- [ ] 👤 外部佐使：加進任一藥方多一份。
- [ ] 👤 有命名或附魔的外部藥材放不進砂鍋（低沉一聲）。
- [ ] 👤 打破煮好的外部湯劑：每一份都掉出來（不可堆疊的成品也一樣）。
- [ ] 👤 外部食物的寒熱：吃了之後寒熱照登記的數值變動。
- [ ] 👤 事件：採收藥材、盛湯、煎焦、配錯、配出散劑、學會藥方、上火／受寒時，範例模組都收得到。
- [ ] 👤 移除範例模組後重進世界：砂鍋裡還沒盛出的外部湯劑變成苦澀藥渣，不會卡住。

以下是已知、沒有修的行為，測到不算新問題：

- 煎焦和配錯事件裡的玩家是當初點火的人，可能已經離線。
- 同一玩家一秒內採收多株，只會送出一次採收事件。
- 打破作物不算採收，只有右鍵採收才送事件。
