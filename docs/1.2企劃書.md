實作和下面草案不同的地方：

- **蜜丸是八種物品，不是一種。** 原本打算用一種物品加物品資料記住散劑種類，但 Script API 的物品資料只能放在不可堆疊的物品上（藥方籤因此是一個一疊），蜜丸要能疊 16 顆，所以改成每種散劑一種丸：明目丸、清熱丸、安神丸、行氣丸、參蟲丸、輕身丸、隱息丸、回春丸。好處是 A Witch Way 的背包自動餵食也認得。
- **營火旁**：草案寫「向 0 回 2」，比平常回得還慢，不合理；改成營火或火爐在 3 格內時，寒冷與炎熱的推力取消，身體照平常速度（每 5 秒 5 點）回到平和。地獄不受營火影響。
- **計時器**：環境會推動寒熱，所以計時器不能在平和時停住；改成一個常駐、每 5 秒一次的輕量迴圈。每位玩家先看腳下兩格、所在的水與時間，只有在冷或熱的地方才掃描附近 7×3×7 格找火源。
- **郎中不賣菌種**：段木茯苓菌種是方塊、不是物品，改成直接用茯苓粉接種。郎中改賣：種子（8 種隨機 2 種，人參籽較貴）、封緘藥籤、空白藥方籤；收購 11 種乾藥材（冬蟲夏草 1 個換 2 綠寶石）。
- **郎中怎麼知道哪裡是藥廬**：兩個藥廬結構裡原本放簸箕的位置（1.1 改成空氣）現在放一個看不見、碰不到的標記方塊，區塊載入時把位置記下來。郎中只在記下的藥廬出現，天黑時不論走到哪裡都會離開。

## 2. 設計原則（沿用 1.1，新增第 6 條）

1. **只有熟與焦**：不做品質等級。丸劑、環境寒熱都不能變相成為「上品」。
2. **每樣東西都有用途**：新物品必須至少接到一個配方、一種效果或一個交易。
3. **沒有無作用的東西**：沒有功能的物品、程式、文字一律不加。
4. **器具用廚房的**：晾曬、切片、研磨、熬湯、泡茶仍在廚房的器具上做；草本只做廚房沒有的（砂鍋、藥缽、香爐、百子櫃）。
5. **沉浸式回饋**：不顯示文字提示，回饋靠聲音、粒子、模型與動畫。
6. **新**：**1.1 的世界要能升級**。1.2 不刪除、不改名任何物品或方塊；新增的方塊狀態都要有預設值。

## 4. 1.2.0 新內容

### A. 丸劑（P1）

散劑效果強但只能當場吃；丸劑讓配好的藥可以帶在身上，用在探險與戰鬥中。

| 項目 | 規格 |
|---|---|
| 做法 | 藥缽放入 2 份同一種散劑與 1 瓶蜂蜜，空手搓三下（沿用搗藥動畫，聲音改軟的），得蜜丸 ×4，還一個空玻璃瓶 |
| 物品 | 每種散劑一種丸（實作時改的，見第 0 節） |
| 效果 | 與原散劑相同的效果、相同等級，**持續時間 ×1.5**；寒熱值 ×0.5 |
| 服用 | 吃的時間 0.4 秒（散劑 0.8 秒）；不給飽食；每 20 tick 最多吃一顆 |
| 堆疊 | 同一種蜜丸可以疊到 16；不同種不會疊在一起 |
| 奇怪藥散 | 不能搓丸（蜂蜜退回、嘶一聲） |
| 藥方 | 不需要另外學；會配散劑就會搓丸 |

需要：蜜丸圖示 8 個（目前是暫代品）。
完成條件：8 種散劑都搓得出對應蜜丸；蜜丸吃下的效果、時間、寒熱正確；不同種不堆疊。

### B. 寒熱與環境（P1）

1.1 的寒熱只在吃喝時變動，平常會自己回到平和，所以溫補與涼飲只有「吃太多會上火」這個用途。1.2 讓環境也推動寒熱：

| 環境 | 每 5 秒 | 理由 |
|---|---|---|
| 站在雪、細雪、冰上，或在雪地群系的露天 | −2 | 受寒 |
| 泡在水裡（夜間或寒冷群系） | −2 | 受寒 |
| 地獄 | +2 | 上火（地獄裡溫補加倍的規則保留） |
| 沙漠、惡地的白天露天 | +1 | 上火 |
| 營火、火爐旁 3 格內 | 取消冷熱，照平常回到平和 | 烤火取暖（實作時改的，見第 0 節） |
| 其他 | 照舊向 0 回 5 | 平和 |

效果沿用 1.1：寒熱到 ±60 有徵兆（泛紅、打冷顫），到 ±100 上火（反胃）或受寒（緩慢）。
於是：去雪山前喝參湯、艾歸湯；下地獄前喝菊花茶、清熱散，都有了理由。

注意：

- 只對生存與冒險模式的玩家計算；創造、旁觀不算。
- 判斷「雪地群系」要查群系。`Dimension.getBiome` 在 `@minecraft/server` 2.7.0 是否可用、回傳什麼，**動工前先查文件確認**；不可用就只看腳下方塊與高度，不看群系。
- 每 5 秒只看一次玩家腳下與身邊幾格，不掃描大範圍。
- 對外 API 新增事件 `constitution_env`（環境讓寒熱跨過 ±60 時），其他模組可以據此做自己的效果。

完成條件：在雪原站 2 分鐘會開始打冷顫；喝參湯可以抵消；地獄裡喝菊花茶可以撐更久；整個過程沒有任何文字。
