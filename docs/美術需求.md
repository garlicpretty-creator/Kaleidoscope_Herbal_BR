## 3. 共通規範

### 3.1 PBR（每張都要）

- 方塊、模型、物品、實體的每張顏色貼圖，都要有同名的 `_normal.png`、`_mer.png` 與 `.texture_set.json`，三張尺寸相同。缺了檢查會失敗（`python3 tools/pbr_audit.py`）。
- MER：R＝金屬度、G＝自發光、B＝粗糙度。取值參考在 [PBR.md](PBR.md)。
- 只有 `ui/`、`particle/` 與物品欄的平面圖示可以不附。
- **16×16 的物品圖示只要交顏色圖**：法線與 MER 由 `tools/icons.py` 依顏色自動產生。

### 3.2 畫風

- 物品圖示：16×16、硬邊、和現有 117 個一致。
- 方塊與模型：沿用現有的共用圖集（`models/plants.png`、`models/bowls.png`、`models/decor.png` 等）時，**不要動到別人已經用的格子**，只畫在空白處。

### 3.3 交件與流程

- 物品圖示：放進 `tools/icon_src/rd/<檔名>.png`，跑 `python3 tools/icons.py`。**不要直接改資源包裡的 PNG**，下次重跑會被蓋掉。
- 蜜丸圖示目前由 `tools/placeholders.py` 產生；正式圖到了之後我會把它們改由 `tools/icons.py` 產生，並把暫代程式拿掉。
- 模型與實體：直接交 Blockbench 匯出的 `.geo.json`（和需要的 `.animation.json`）與貼圖，我負責接上方塊或實體、跑檢查。
- 交件後我會跑 `python3 tools/check_refs.py`、`python3 tools/audit.py`、`python3 tools/pbr_audit.py`，都通過才合併。

## 4. 不能動或要小心的地方

| 東西 | 為什麼 |
|---|---|
| **動畫用的骨架** | 藥缽的 `pestle`、砂鍋的 `lid_closed`、百子櫃的 `drawer_5` 與 `shown_1`、13 種湯碗的 `soup` 與 `toppings`：動畫的各個姿勢是從這幾根骨架複製出來的（`pestle_up`、`lid_bob`、`drawer_5_open`、`soup_1` 等）。改這些模型時骨架名稱要保留；改完我會重跑 `tools/anim_models.py` 重新產生姿勢 |
| 其他被程式點名的骨架 | 方塊的顯示規則靠骨架名稱切換（例如砂鍋的 `liquid`、`lid_open`、`lid_ready`，藥缽的 `contents_ground`）。改名會讓那個部位永遠不顯示 |
| 名為 `shown` 的材質 | 砂鍋、百子櫃顯示「裡面放的是什麼藥材」的那一面，程式會換上該藥材的圖示。這一面保持一個平面、材質名保持 `shown` |
| 山野藥廬的標記方塊 | `hut_marker` 刻意是透明、碰不到的，用來讓程式知道哪裡是藥廬。**不要給它畫外觀** |
| 山野藥廬的結構檔 | 結構裡原本放簸箕的位置現在是那個標記方塊。若要重做藥廬，請保留它（或告訴我新位置） |
| 方塊與物品的 ID、檔名 | 程式、圖鑑、配方都用這些名稱找東西 |

### 進遊戲確認（2026-11-18，Claude）

環境：Minecraft 基岩版 26.65（Windows），Vibrant Visuals 開啟，廚房 1.6.6 + 草本（這次的建置），超平坦測試世界「Herbal 1.2 Art Test」。

- 蜜丸：八種放在快捷欄上，顏色都分得出來，旁邊放茯苓粉對照也不會搞混。
- 走方郎中：正面、背面、側面與走路中都看過。斗笠沒有穿進藥簍，幌子跟著右手擺動。
  - **發現並修正**：幌子和右袖正面在同一個平面（z −2），重疊處有條紋閃爍。幌子往前移到 z −2.6 後消失（`tools/herbalist_model.py`，只改模型，貼圖不變）。
  - 天黑時郎中照設計離開，所以夜間沒有看到他。
- 段木茯苓菌種：雲杉原木東西南北四面都貼得上，白色菌絲加深褐突起，和靈芝菌種分得出來。
- 香爐：白天看是霧面陶器，沒有金屬反光；點燃版通氣孔一圈在白天也看得到橘光。
- 光源：夜裡紙燈籠在草地上投出暖紅色的光，點燃的香爐蓋上有暖光。
- 葉片透光：逆光看時葉片沒有變黑，花瓣透亮，沒有全黑或全白的錯誤。效果偏淡；沒有和不透光的版本並排比較。

沒有看的：郎中的待機（他只有走路與看玩家）、關掉 Vibrant Visuals 時的外觀（遊戲內切換圖形模式這個選項是關的，沒有去改你的設定）。
